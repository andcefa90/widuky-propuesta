# WIDUKY — Move Different

Propuesta conceptual e interactiva de la futura experiencia digital de WIDUKY Pilates (Los Angeles, California).

Es un prototipo de presentación: todos los datos son ficticios y no hay reservas, pagos ni cuentas reales.
Fotografías de referencia de Unsplash.

## Desarrollo

```bash
npm install
npm run dev
```

Cada push a `main` se publica automáticamente en GitHub Pages.
